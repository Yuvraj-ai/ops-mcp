# Idempotency Keys Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `reconfirm_order` and `issue_refund` idempotent via an agent-generated `idempotency_key` input. Retries with the same key return the stored result instead of re-executing.

**Architecture:** New `idempotency_keys` table stores `(tool_name, key, result)`. Each write-tool handler checks for an existing key at the top of its body; if found, returns the stored result (still audit-logged). After fresh execution, the result is stored. Audit logging happens for both fresh and replayed paths.

**Tech Stack:** PostgreSQL (`pg`), pg-mem for tests, existing `OpsRepository` pattern.

---

## Scope

Single cohesive feature: idempotency for 2 write tools. No subsystem decomposition needed.

## Files to modify
- `src/db/schema.sql` — add `idempotency_keys` table
- `src/db/queries.ts` — add `getIdempotencyResult()` and `storeIdempotencyResult()` methods
- `src/tools/definitions.ts` — add `idempotency_key` to zod schemas, update descriptions, refactor both write handlers
- `src/tests/tools.test.ts` — update all write-tool calls to include `idempotency_key`, add 2 new idempotency test cases
- `docs/handoff.md` — update pending changes + changelog

## Key decisions (from design spec)
- Idempotency check wraps the ENTIRE handler (including validation), so retries return the exact same result
- Audit logging happens for every call (fresh + replayed)
- Idempotency key is only stored for fresh executions (not replays)
- Both repo methods are best-effort — DB errors caught, logged to console, never block the operation
- No TTL on idempotency keys (production concern, noted in README)

### Task 2: Add idempotency methods to `OpsRepository`

**File:** Modify: `src/db/queries.ts`

- [ ] **Step 1: Add two methods after `logAction`**

```typescript
async getIdempotencyResult(toolName: string, key: string): Promise<any | undefined> {
  try {
    const result = await this.pool.query(
      "SELECT result FROM idempotency_keys WHERE tool_name = $1 AND key = $2",
      [toolName, key]
    );
    if (result.rows.length === 0) return undefined;
    return JSON.parse(result.rows[0].result);
  } catch (err) {
    console.error("Idempotency check failed, proceeding as fresh execution:", err);
    return undefined;
  }
}

async storeIdempotencyResult(toolName: string, key: string, result: any): Promise<void> {
  try {
    await this.pool.query(
      "INSERT INTO idempotency_keys (tool_name, key, result) VALUES ($1, $2, $3)",
      [toolName, key, JSON.stringify(result)]
    );
  } catch (err) {
    console.error("Failed to store idempotency result:", err);
  }
}
```

### Task 4: Refactor `reconfirm_order` handler with idempotency

**File:** Modify: `src/tools/definitions.ts` (lines 108-140)

- [ ] **Step 1: Replace the handler body with idempotency-aware version**

```typescript
        handler: async (input: { order_id: string; idempotency_key: string; confirmed_by_operator: true }) => {
          let result: any;
          let isReplay = false;

          const existing = await repo.getIdempotencyResult("reconfirm_order", input.idempotency_key);
          if (existing) {
            result = existing;
            isReplay = true;
          } else {
            try {
              const order = await repo.getOrder(input.order_id);
              if (!order) {
                result = { error: `No order found with ID ${input.order_id}.` };
              } else if (order.status === "refunded" || order.status === "cancelled") {
                result = { error: `Order ${input.order_id} is '${order.status}' and cannot be reconfirmed.` };
              } else if (order.status !== "failed") {
                result = {
                  error: `Order ${input.order_id} has status '${order.status}', not 'failed'. Re-investigate before acting.`,
                };
              } else {
                const r = await repo.reconfirmOrder(input.order_id);
                result = {
                  success: true,
                  new_order_status: "confirmed",
                  new_hold_id: r.newHoldId,
                  note: "Call get_shipment_status next to verify fulfillment picked this up.",
                };
              }
            } catch (err) {
              result = { error: err instanceof Error ? err.message : String(err) };
            }
          }

          await repo.logAction({
            order_id: input.order_id,
            tool_name: "reconfirm_order",
            input_json: JSON.stringify(input),
            result_json: JSON.stringify(result),
            success: !("error" in result),
          });

          if (!isReplay) {
            await repo.storeIdempotencyResult("reconfirm_order", input.idempotency_key, result);
          }

          return result;
        },
```

        handler: async (input: {
          order_id: string;
          idempotency_key: string;
          amount: number;
          reason: string;
          confirmed_by_operator: true;
        }) => {
          let result: any;
          let isReplay = false;

          const existing = await repo.getIdempotencyResult("issue_refund", input.idempotency_key);
          if (existing) {
            result = existing;
            isReplay = true;
          } else {
            try {
              const order = await repo.getOrder(input.order_id);
              if (!order) {
                result = { error: `No order found with ID ${input.order_id}.` };
              } else if (order.status === "refunded") {
                result = { error: `Order ${input.order_id} has already been refunded.` };
              } else {
                const payment = await repo.getPaymentByOrder(input.order_id);
                if (!payment || payment.status !== "captured") {
                  result = {
                    error: `Order ${input.order_id} has no captured payment to refund (payment status: ${payment?.status ?? "none"}).`,
                  };
                } else {
                  const r = await repo.issueRefund(input.order_id);
                  result = {
                    success: true,
                    refund_id: r.refundId,
                    new_order_status: "refunded",
                    reason: input.reason,
                  };
                }
              }
            } catch (err) {
              result = { error: err instanceof Error ? err.message : String(err) };
            }
          }

          await repo.logAction({
            order_id: input.order_id,
            tool_name: "issue_refund",
            input_json: JSON.stringify(input),
            result_json: JSON.stringify(result),
            success: !("error" in result),
          });

          if (!isReplay) {
            await repo.storeIdempotencyResult("issue_refund", input.idempotency_key, result);
          }

          return result;
        },
